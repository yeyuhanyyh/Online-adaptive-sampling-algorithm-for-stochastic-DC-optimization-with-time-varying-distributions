# An Online Adaptive Sampling Algorithm for Stochastic Difference-of-convex Optimization with Time-varying Distributions

This repository contains MATLAB code for the numerical experiments in the paper **An Online Adaptive Sampling Algorithm for Stochastic Difference-of-convex Optimization with Time-varying Distributions**.

The cleaned version of the repository keeps only three MATLAB files:

- `run_main_paper_experiments.m`
- `run_appendix_experiments.m`
- `online_sparse_robust_regression_suite.m`

The goal is simple: one main driver for the paper figures, one optional driver for the appendix figures, and one self-contained implementation file that contains all experiment logic.

---

## Project Overview

We study online sparse robust regression under time-varying data distributions. At time step `t`, the feature vector is sampled from `[-1, 1]^p`, and the label is generated by

`y_t = x_t' * (beta_opt + delta_t) + eps`,

where `eps ~ N(0, 1)`.

The objective is

`E[ |y - <beta, x>| ] + lambda * sum_j min(1, alpha * |beta_j|)`.

The code compares five methods:

1. **Adaptive ospDCA (ours)**
2. **ospDCA with predetermined sample size `t^2.1`**
3. **S(p)DCA with one new sample per iteration and cumulative sample averages**
4. **ospDCA with fixed sample size 100**
5. **ospDCA with fixed sample size 1000**

---

## Experiment Setup

### Common parameters

- `alpha = 1`
- `lambda = 0.01`
- proximal coefficient `mu = 1`
- adaptive-sampling parameter `alpha_g = 0.45`
- initial sample size = `10`

### Main paper experiments

These reproduce Figures 1 and 2 in the main paper.

- **Experiment (a):** `p = 50`, `beta_opt = [10, -15, 0, ..., 0]`
- **Experiment (b):** `p = 200`, `beta_opt = [10, -15, 0, ..., 0]`
- distribution shift: `delta_t = (-1)^t * 100 * t^(-2) * 1_p`

### Appendix experiments

These reproduce Figures 3 and 4 in the appendix.

- **Experiment (c):** `p = 100`, `beta_opt = [5, -5, 0, ..., 0]`
- **Experiment (d):** `p = 200`, `beta_opt = [5, -5, 0, ..., 0]`
- **Experiment (e):** `p = 50`, `beta_opt = [5, -5, 0, ..., 0]`, `delta_t = (-1)^t * 5000 * t^(-2) * 1_p`

## How to Run

Open MATLAB in the repository folder.

### Main paper figures

Run:

```matlab
run_main_paper_experiments
```

This generates:

- `results/main_figure1_behavior.png`
- `results/main_figure2_sample_size.png`
- `results/main_summary.mat`

### Appendix figures

Run:

```matlab
run_appendix_experiments
```

This generates:

- `results/appendix_figure3_behavior.png`
- `results/appendix_figure4_sample_size.png`
- `results/appendix_summary.mat`

## Notes on This Cleaned Version

Compared with the earlier repository state, this cleaned version:

- removes old plotting helpers, temporary notebooks, and cached `.mat` files;
- removes unrelated toy / exploratory scripts that do not belong to the sparse robust regression experiments;
- merges the experiment logic into one reusable MATLAB implementation file;
- separates the main-paper experiments from the appendix experiments;
- saves final figures and summaries under a single `results/` folder.
