# An Online Adaptive Sampling Algorithm for Stochastic Difference-of-convex Optimization with Time-varying Distributions

This repository contains MATLAB code for the numerical experiments in the paper **An Online Adaptive Sampling Algorithm for Stochastic Difference-of-convex Optimization with Time-varying Distributions**.

The experiments study online sparse robust regression under time-varying distributions and compare the proposed adaptive ospDCA method with four baselines. The repository is organized so that the main-paper experiments and the appendix experiments can be run separately, while sharing one common implementation file.

* * *

## Project Overview

The repository contains two driver scripts and one shared implementation file.

### Main paper experiments

File: `run_main_paper_experiments.m`

This script reproduces the main-paper figures. It runs the following two settings:

- **Experiment (a):** $p = 50$, `beta_opt = [10, -15, 0, ..., 0]`
- **Experiment (b):** $p = 200$, `beta_opt = [10, -15, 0, ..., 0]`

### Appendix experiments

File: `run_appendix_experiments.m`

This script reproduces the appendix figures. It runs the following three settings:

- **Experiment (c):** $p = 100$, `beta_opt = [5, -5, 0, ..., 0]`
- **Experiment (d):** $p = 200$, `beta_opt = [5, -5, 0, ..., 0]`
- **Experiment (e):** $p = 50$, `beta_opt = [5, -5, 0, ..., 0]`, with a larger time-varying shift

### Shared implementation

File: `online_sparse_robust_regression_suite.m`

This file contains the shared implementation of data generation, the five compared methods, stopping rules, figure generation, and saving of summary `.mat` files.

## Model Setting

At time step $t$, the feature vector is sampled from $[-1,1]^p$, and the response is generated by

```math
y_t = x_t^\top (\beta^\star + \delta_t) + \varepsilon_t,
\qquad
\varepsilon_t \sim N(0,1).
```

The sparse robust regression objective is

```math
E\big[|y - x^\top \beta|\big]
+ \lambda \sum_{j=1}^p \min(1,\alpha |\beta_j|).
```

The time-varying distribution enters through the shift vector $\delta_t$.

For the main paper experiments and appendix experiments (c) and (d), the shift is

```math
\delta_t = (-1)^t \cdot 100\, t^{-2} \cdot (1,\ldots,1)^\top.
```

For appendix experiment (e), the shift becomes

```math
\delta_t = (-1)^t \cdot 5000\, t^{-2} \cdot (1,\ldots,1)^\top.
```

* * *

## Compared Methods

The code compares five methods.

1. **Adaptive ospDCA**  
   The proposed method chooses the sample size adaptively according to the current iterate change.

2. **ospDCA with predetermined sample size**  
   The sample size at iteration $t$ follows the schedule $N_t = \lceil t^{2.1} \rceil$.

3. **S(p)DCA**  
   One new sample is added at each iteration, and the sample-average approximation is built cumulatively.

4. **ospDCA with fixed sample size 100**

5. **ospDCA with fixed sample size 1000**

All five methods are compared by the distance to `beta_opt`, by wall-clock time, and by sample-size behavior.

## Numerical Experiment Setup

### Common parameters

- $\alpha = 1$
- $\lambda = 0.01$
- proximal coefficient $\mu = 1$
- adaptive-sampling constants: `C_g = 1`, $\alpha_g = 0.45$
- initial sample size = 10
- stopping tolerance on successive iterates = `1e-10`

The implementation uses MATLAB `fminunc` to solve each DCA subproblem.

### Time budgets used in the figures

- **(a)** 5 seconds
- **(b)** 20 seconds
- **(c)** 8 seconds
- **(d)** 20 seconds
- **(e)** 5 seconds

A fixed random seed is used for reproducibility.

## How to Run

Open MATLAB in the repository folder and run one of the following scripts.

### Main paper figures

```matlab
run_main_paper_experiments
```

This script generates:

- `results/main_figure1_behavior.png`
- `results/main_figure2_sample_size.png`
- `results/main_summary.mat`

### Appendix figures

```matlab
run_appendix_experiments
```

This script generates:

- `results/appendix_figure3_behavior.png`
- `results/appendix_figure4_sample_size.png`
- `results/appendix_summary.mat`

* * *

## Generated Files

The saved figures have the following meaning.

- `main_figure1_behavior.png`: performance plots for experiments (a) and (b), including distance to `beta_opt` versus iterations and versus wall-clock time
- `main_figure2_sample_size.png`: sample-size trajectories for adaptive ospDCA and predetermined-schedule ospDCA in experiments (a) and (b)
- `appendix_figure3_behavior.png`: performance plots for experiments (c), (d), and (e)
- `appendix_figure4_sample_size.png`: sample-size trajectories for the appendix experiments

The `.mat` files store the corresponding numerical summaries, including the generated curves, final iterates, elapsed times, and sample sizes.
